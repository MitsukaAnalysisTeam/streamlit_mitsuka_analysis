# AIに聞く 質問セットの確認シート

店のスタッフの方に、質問の言い回しと「こう答えるべき」を確認してもらうための一覧です。

確認してほしいこと:

1. 実際に店で言いそうな言い回しか（言わないもの、不自然なものは直してください）
2. 「期待する答え」は妥当か（聞き返しにすべき・別のグラフのほうがよい、など）

期間（先月・去年の夏など）は、質問文から別の処理で読み取るため、この表では「期待する答え」に含めていません。

`dataset.jsonl` の中身から自動で作っています。
